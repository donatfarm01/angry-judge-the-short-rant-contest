One short, funny rant about a small everyday annoyance: the self-checkout
machine that accuses you of stealing the milk you just paid for, in front
of a whole queue. The program writes the rant to `/output/entry.txt`.

## Run

`python3 main.py` — validates the 1–400 character gate, writes the entry,
and prints its length and sha256 (with and without trailing newline).
